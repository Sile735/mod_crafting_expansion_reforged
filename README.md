# Crafting Expansion Reforged

A crafting mod for **Battle Brothers** with the **[Reforged](https://github.com/Battle-Modders/mod-reforged)** mod.
It turns the Taxidermist into a real workshop: almost every **anatomist potion** can be crafted, rare event items get recipes,
and the classic trophy necklaces and padding can be **upgraded** into stronger versions with their own art.

> **Tip:** in *Mod Options → Reforged Mod → General*, set **Blueprints Visible When** to **Always** to see every recipe in the Taxidermist, even before you own the ingredients.

Ingredient names below are the names shown in game.

## Other

- **Geist Tear** (Reforged loot) is a crafting ingredient.
- The Alchemist follower can still save ingredients, but never the item that is being upgraded (no duplicated necklaces or padding).
- Crafting tooltips ("Can be used to craft items") come from Reforged and include all of this mod's recipes.

---

## Requirements

- Reforged **0.9+** (with its requirements: MSU, Modern Hooks, Dynamic Perks, Stack Based Skills, …)

## Installation

Download the zip from the latest [release](../../releases) and put it (unextracted) into the game's `data` folder.
The mod is **safe to add to an existing savegame**.
